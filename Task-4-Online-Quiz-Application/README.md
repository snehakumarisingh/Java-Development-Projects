# Online Quiz Application

A console-based quiz application developed using Java.

## Features
- Multiple-choice questions (MCQs)
- User answer validation
- Automatic score calculation
- Percentage calculation
- Final result evaluation

## Technologies Used
- Java
- OOP Concepts
- ArrayList
- Scanner

## How to Run
1. Open the `src` folder.
2. Compile: `javac Question.java OnlineQuizApplication.java`
3. Run: `java OnlineQuizApplication`

## Project Structure
- `Question.java` – Stores question details and options.
- `OnlineQuizApplication.java` – Handles quiz execution and result calculation.
