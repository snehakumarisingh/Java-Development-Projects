# Student Management System

A simple console-based Java application to manage student records.

### Features
- Add student details (ID, name, marks).
- View all students.
- Search students by ID.
- Prevent duplicate student IDs.
- Handle invalid inputs.

### Technologies Used
- Java
- OOP
- ArrayList
- Exception Handling

### How to Run
```bash
javac -d out Task-1-Student-Management-System/src/Student.java Task-1-Student-Management-System/src/StudentManagementSystem.java
java -cp out StudentManagementSystem
```
